# K64 v0.3.38 - Shell In-Path Linux App Launch

This release adds a PATH-like shell resolver through `/etc/path/inpath.cfg`.
After built-ins, service commands, service startup, and driver startup are tried,
the shell searches configured executable directories. The default configuration
includes `/ex`, `/compat/linux/bin`, and `/compat/linux/usr/bin`.

Native K64 ELFs can still be launched from `/ex` by name. Staged Linux x86_64
ELFs under `/compat/linux/...` are now launched through KLCS automatically, so
commands such as `nano --version`, `tcc -v`, `git --version`, and `sl` can be
used directly without typing `klcs run`.

The explicit `klcs run <path>` form remains available as the verbose diagnostic
path. Direct shell launches use the quieter `klcs runq` path and suppress K64
ELF wrapper status lines around execution.
