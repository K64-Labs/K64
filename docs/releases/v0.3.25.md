# K64 v0.3.25 - Boot Flow and Installer Polish

This release improves the first-user experience around K64's K64XFS-only system image. The ISO GRUB menu now offers explicit "Try K64 live" and "Install K64" choices, the kernel records a `boot_mode` from the Multiboot command line, and installer mode opens with a text UI-style guide for reviewing disks, creating a user, and installing a bootable K64XFS system disk.

K64 now starts the shell behind a real login gate instead of silently dropping into the guest account. The existing `guest / guest` account remains available for tests and live use, while installed systems can create a sudo-capable account with `install user <name> <password> [sudo]` before running `install <device> yes`.

The service layer is also documented more clearly. K64 services already have private VM spaces and service-call ownership, but most service handlers are still kernel-hosted because a safe message-driven Ring-3 service host is not complete yet. v0.3.25 improves the user flow without pretending that every service has become an untrusted Ring-3 process.
