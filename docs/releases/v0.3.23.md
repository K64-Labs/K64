# K64 v0.3.23 - K64XFS Modern Filesystem Core

This release introduces K64XFS, a new modern block-backed filesystem for K64. Unlike the original image-backed K64FS, K64XFS is designed around block allocation, persistent UID/GID/mode metadata, extents, mount-state tracking, checksummed metadata, a block-cache foundation, and a metadata journal skeleton for crash-aware updates.

K64FS remains available as BootFS/LegacyFS for compatibility. K64XFS is introduced as an experimental high-end filesystem core with `xfsctl` tooling, format/mount/stat/list/write/read/check paths, and a roadmap toward becoming the future K64 root filesystem.

K64XFS is not yet a full production filesystem. Compression, snapshots, encryption, ACLs, indexed directories, indirect extents, full fsck repair, complete journal replay, and root migration remain future work.
