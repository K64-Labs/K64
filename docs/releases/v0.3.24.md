# K64 v0.3.24 - K64XFS-Only Root

This release removes the legacy image filesystem from the active boot and root path. K64 now builds `root.xfs`, boots disk images through a GRUB `k64xfs` reader, passes `root.xfs` as the ISO fallback module, and backs the stable `k64_fs_*` kernel API with K64XFS instead of the old image-rewrite implementation.

K64XFS is now the only runtime root filesystem used by the standard nongraphical kernel build. The old image packer and GRUB reader are removed from the build, release artifacts now publish `root.xfs`, and the service/installer/status paths report K64XFS capacity and usage.
