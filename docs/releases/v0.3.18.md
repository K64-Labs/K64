# K64 v0.3.18 - Filesystem Hardening Core

This release strengthens legacy image filesystem without replacing the boot-compatible image format. It adds richer file metadata, stricter path and image validation, recursive directory creation, file range read/write helpers, truncate support, richer shell stat output, and a userland `stat(path, out)` syscall wrapper.

legacy image filesystem remains a compact image-backed filesystem, not a full journaling POSIX filesystem. It still uses whole-image compaction/writeback for persistence, but the kernel now has a cleaner foundation for safer mutation, metadata-aware userland tools, and future block-oriented allocation work.
