# K64 v0.3.36 - KLCS Foundation

This release introduces the first foundation for KLCS, the K64 Linux Compatibility Service.

KLCS is a K64 service, not a Linux subsystem inside the kernel. It starts the compatibility architecture with a Linux x86_64 syscall-frame type, process personality constants, Linux errno mapping, a syscall dispatch table, FD/path translation foundations, ELF64 validation, trace controls, service calls, shell diagnostics, and host/smoke tests.

The new `klcs` command supports:

- `klcs status`
- `klcs syscalls`
- `klcs trace on`
- `klcs trace off`
- `klcs trace`
- `klcs run <path>`

`klcs run` currently validates candidate static x86_64 Linux ELF files and rejects invalid or dynamic ELF files clearly. Full Linux binary execution is not claimed yet; the next milestone is mapping static ELF `PT_LOAD` segments into Linux-personality user processes and routing the x86_64 Linux `syscall` instruction into KLCS.

K64 remains native by design. KLCS exists to route selected Linux application behavior into K64 service calls without turning K64 into Linux.
