# K64 v0.3.17 - First Real Userland Core

This release turns K64's ring-3 ELF path into a more coherent userland foundation. It adds stable process identity, parent/child tracking, waitpid flags, zombie/reap lifecycle behavior, stronger syscall error codes, a real file-descriptor foundation, first anonymous pipes, expanded libc wrappers, and new smoke programs for process, fd, pipe, and security behavior.

K64 is still not POSIX-compatible and does not yet provide fork/execve, a dynamic linker, shared libraries, full sockets, or a mature VFS. Spawned child execution is currently limited to stable process identity reservation until independent user-context scheduling is ready. Even with that limit, v0.3.17 establishes the core process and I/O concepts needed for future userland milestones.
